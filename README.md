# novaretail-analysis-clientes
# NovaRetail: Análisis Exploratorio y Comportamiento de Clientes

Análisis exploratorio de datos (EDA) y validación estadística para **NovaRetail**, enfocado en identificar patrones de comportamiento de los clientes, diferencias entre segmentos y factores clave asociados a sus métricas principales.

---

## 📋 Objetivo del Proyecto
Evaluar la calidad de los datos de clientes de NovaRetail y responder preguntas de negocio mediante análisis estadístico, detectando tendencias relevantes que permitan optimizar estrategias de retención y toma de decisiones comerciales.

---

## 🛠️ Tecnologías y Librerías Utilizadas
* **Lenguaje:** Python 3
* **Manipulación y Análisis de Datos:** `pandas`, `numpy`
* **Visualización de Datos:** `matplotlib`, `seaborn`
* **Estadística:** `scipy.stats` (pruebas de hipótesis y correlación)
* **Entorno de Desarrollo:** Jupyter Notebook

---

## 📂 Estructura del Repositorio
* `S8_Student_Version_Project_NovaRetail_.ipynb`: Notebook principal con el código completo, limpieza de datos, visualizaciones y conclusiones ejecutivas.
* `README.md`: Documentación general del proyecto.

---

## 🔍 Metodología y Etapas del Análisis
1. **Diagnóstico Inicial y Limpieza de Datos:** Revisión de tipos de datos, tratamiento de valores ausentes, detección de duplicados y estandarización de variables.
2. **Análisis Exploratorio de Datos (EDA):** Evaluación de distribuciones, métricas descriptivas (media, mediana, dispersión) y segmentación de variables categóricas y numéricas.
3. **Visualización de Hallazgos:** Gráficos comparativos para identificar comportamientos atípicos y patrones por grupo de clientes.
4. **Pruebas Estadísticas:** Validación de hipótesis para determinar si las diferencias observadas entre segmentos son estadísticamente significativas.
5. **Conclusiones y Recomendaciones:** Síntesis de resultados accionables orientados al negocio.
